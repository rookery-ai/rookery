Set up Composio

Composio is a free service. Follow these steps — it takes about 5 minutes.

  1. 1

    Create a free Composio account

    Sign up at composio.dev — no credit card required.

    Sign up at composio.dev →
  2. 2

    Create an API key

    Go to Settings → API Keys and create a new key. Select Read All and Write All permissions, then copy the key.

  3. 3

    Add the key to your Secrets

    Go to the Secrets page and add a new secret named COMPOSIO_API_KEY with your key as the value. It will be encrypted with your master password.

    Go to Secrets →
  4. 4

    Connect your services

    In your Composio dashboard, go to Connections and connect Google Drive, Notion, Slack, or any other service. Composio handles login securely — you never share passwords with Simple Agents.

    Open Composio Connections →
  5. ✓

    Done — your agents are ready

    Come back here and you'll see "Composio is connected ✓". When you create agents, the designer will automatically know about your connected services.
