How agents use your services

When you create an agent that needs Google Drive, Notion, or any other connected service, the designer will automatically suggest using Composio. The generated code uses the v3 REST API: 

from composio_helper import get_connection, composio_execute
import os

# Get the connected account
conn_id, user_id = get_connection("notion")

# Search Notion pages
result = composio_execute(
    "NOTION_SEARCH_NOTION_PAGE",
    conn_id, user_id,
    {"query": "My Database"}
)

# List Google Drive files
conn_id, user_id = get_connection("google-drive")
result = composio_execute(
    "GOOGLEDRIVE_LIST_FILES_IN_FOLDER",
    conn_id, user_id,
    {"folder_id": "root"}
)

The API key is injected automatically — agents never see it in plain text and it's never stored in AGENT.md.

Get started with Composio

Composio is a free service that connects your AI agents to 250+ external apps. Follow these steps to set it up — it takes about 5 minutes.

  1. 1

    Create a free Composio account

    Sign up at composio.dev — no credit card required.

    Sign up at composio.dev →
  2. 2

    Copy your API key

    After signing in, go to Settings → API Keys and create a new key. Copy the value — it starts with ak_ or c_live_.

  3. 3

    Add the key to your Secrets

    Go to the Secrets page and add a new secret with the name COMPOSIO_API_KEY and paste your key as the value. It will be encrypted with your master password.

    Go to Secrets →
  4. 4

    Connect your services in Composio

    In your Composio dashboard, go to Connections and connect Google Drive, Notion, Slack, or any other service you want your agents to use. Composio handles the login securely — you never share passwords with Simple Agents.

    Open Composio Connections →
  5. ✓

    Done — your agents are ready

    Come back here and you'll see "Composio configured ✓". When you create agents, the designer will automatically know you have Composio and can suggest workflows using your connected services.
